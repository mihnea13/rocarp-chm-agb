# Data

The raster products are **not** stored in this repository.

GitHub enforces a hard 100 MB limit per file and a 2 GB limit per push, and it is
not an archival repository: it issues no persistent identifier, and repositories
can be renamed, made private or deleted. The products will therefore be deposited
on Zenodo, which issues a DOI, checksums every file and preserves the record.

When the release happens, this file will be replaced by the download links and by
the dataset DOI. The Zenodo *concept DOI* resolves to the most recent version of
the record, so a single link remains valid across all future versions.

Expected: **Q1 2027**.
